# Canal histórico de comentarios de a.0.6.5.beta

Desde a.0.6.6.beta se utiliza el formulario de soporte desde la app.

Los comentarios aceptados por el servicio aparecen en archivos de texto. Cada archivo incluye el tipo y el modelo del dispositivo y el texto que la persona confirmó publicar. En el formulario, evitá incluir datos personales.

La recepción queda habilitada cuando la configuración contiene la dirección de un servicio HTTPS activo. La app indica si ese servicio está disponible.
